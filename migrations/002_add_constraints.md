# Миграция 002. Добавление ограничений и индексов

## Описание
Добавление правил валидации в код приложения (так как JSON не поддерживает ограничения СУБД) и индексов для ускорения поиска.

## Ограничения в коде (C#)
1. Проверка `status` при сохранении заявки (только из списка).
2. Проверка `laborHours >= 0` в осмотрах.
3. Проверка `workCost >= 0` в сметах.
4. Проверка существования `clientId` и `machineId` при создании заявки.

## Индексы (Dictionary в памяти)
При загрузке JSON-файлов данные индексируются:
- `orders.json` → `Dictionary<int, Order>` по `id`.
- `users.json` → `Dictionary<string, User>` по `login`.
- `machines.json` → `Dictionary<string, Machine>` по `serialNumber`.

## Обоснование индексов
1. Поиск заявки по ID используется в 80% операций (открытие карточки).
2. Поиск пользователя по логину используется при авторизации.
3. Поиск станка по серийному номеру используется в карточке станка.
