# Health-check системы RepairIS

## Назначение

Health-check предназначен для проверки работоспособности системы и целостности JSON-файлов при запуске.

## Что проверяется

1. Наличие всех JSON-файлов данных.
2. Корректность чтения JSON-файлов.
3. Доступность записи в файлы.

## Алгоритм

1. При запуске приложение вызывает метод HealthCheck.Run().
2. Метод проверяет наличие каждого JSON-файла.
3. Если файла нет — создаёт пустой.
4. Проверяет чтение и запись.
5. Возвращает результат: OK или список проблем.

## Пример использования

```csharp
var result = HealthCheck.Run();
if (!result.IsHealthy)
{
    MessageBox.Show(result.Message, "Ошибка проверки");
}
```
