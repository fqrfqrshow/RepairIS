## 4. Pre-commit

### Настройка
pre-commit install


### Применение
При каждом коммите запускаются:
1. `trailing-whitespace` — удаление пробелов в конце строк.
2. `end-of-file-fixer` — добавление пустой строки в конце файла.
3. `check-yaml` — проверка YAML-файлов.
4. `check-json` — проверка JSON-файлов.
5. `dotnet format --verify-no-changes` — проверка форматирования.

### Результат
Все коммиты проходят проверки pre-commit успешно.
