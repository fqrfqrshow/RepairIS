### Пример модульного теста

Ниже приведён пример теста для проверки метода CreateOrder:

```csharp
[Fact]
public void CreateOrder_ShouldCreateNewOrder_WithGeneratedId()
{
    // Arrange (Подготовка)
    var facade = new RequestSystemFacade();
    var request = new Request
    {
        MachineId = 1,
        ClientId = 1,
        Description = "Тестовая неисправность",
        Status = "Ожидает обработки"
    };

    // Act (Действие)
    facade.CreateOrder(request);

    // Assert (Проверка)
    Assert.True(request.Id > 0);
    Assert.Equal("Ожидает обработки", request.Status);
}
```

### Позитивные и негативные сценарии

1. **Позитивные сценарии:** создание заявки, обновление статуса, сохранение сметы, добавление мастера.
2. **Негативные (граничные) сценарии:** получение заявки с несуществующим ID (возврат null), обработка отсутствующего JSON-файла (возврат пустого списка), передача null в метод сохранения.
