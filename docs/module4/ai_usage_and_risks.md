### Промпт (DeepSeek)
Напиши unit-тесты на xUnit для следующего метода C#:

public void SaveEstimate(Estimate estimate)
{
    if (estimate == null)
        throw new ArgumentNullException(nameof(estimate));

    estimate.Id = _estimates.Count > 0 
        ? _estimates.Max(e => e.Id) + 1 
        : 1;
    _estimates.Add(estimate);
    SaveToFile();
}

### Сгенерированный ИИ код

```csharp
[Fact]
public void SaveEstimate_WithNull_ThrowsArgumentNullException()
{
    var adapter = new EstimateAdapter();
    Assert.Throws<ArgumentNullException>(() => adapter.SaveEstimate(null));
}

[Fact]
public void SaveEstimate_WithValidEstimate_GeneratesId()
{
    var adapter = new EstimateAdapter();
    var estimate = new Estimate { RequestId = 1, WorkCost = 100 };
    adapter.SaveEstimate(estimate);
    Assert.True(estimate.Id > 0);
}

[Fact]
public void SaveEstimate_GeneratesUniqueIds()
{
    var adapter = new EstimateAdapter();
    var e1 = new Estimate { RequestId = 1 };
    var e2 = new Estimate { RequestId = 2 };
    adapter.SaveEstimate(e1);
    adapter.SaveEstimate(e2);
    Assert.NotEqual(e1.Id, e2.Id);
}
```

## 5. Выявленные ограничения и риски

### Риск 1. Конфиденциальность
1. Облачные ИИ-сервисы (DeepSeek, Copilot) отправляют код на сервер провайдера.
2. В проекте используются персональные данные клиентов.
3. **Митигация:** использовать локальные модели (Ollama, LM Studio) для работы с чувствительным кодом.

### Риск 2. Лицензирование
1. Сгенерированный ИИ код может совпасть с лицензированным.
2. **Митигация:** проверка сгенерированного кода через OWASP Dependency-Check, Trivy.

### Риск 3. Галлюцинации
1. ИИ может придумать несуществующие методы.
2. Пример: ИИ предложил метод _estimates.Count() вместо _estimates.Count, что вызвало бы ошибку компиляции.
3. **Митигация:** обязательная ручная проверка, компиляция, тестирование.

### Риск 4. Необходимость верификации
1. Любой сгенерированный код требует проверки.
2. **Митигация:** использовать ИИ как усилитель, а не замену.

### Риск 5. Ответственность разработчика
1. За ошибки в коде отвечает разработчик, а не ИИ.
2. Фраза «Мне так написал ИИ» не является оправданием.
3. **Митигация:** профессиональная этика — понимать код, который отправляешь в production.
