# Результаты проверки восстановления резервной копии

## 1. Цель проверки
Убедиться, что резервная копия JSON-файлов восстанавливается корректно и данные не теряются.

## 2. Подготовка
1. Исходные данные: 3 пользователя, 2 станка, 1 мастер, 2 заявки, 1 осмотр, 1 смета.
2. Создан архив `backup_2026-11-10.zip` с файлами из папки `data/`.
3. Архив сохранён в `backup/local/`.

## 3. Процедура проверки
1. **Симуляция сбоя:** удалена папка `data/` с исходными файлами.
2. **Восстановление:** распакован архив `backup_2026-11-10.zip` в папку `data/`.
3. **Запуск приложения:** приложение запущено, данные загружены.

## 4. Результаты сверки

|---|---|---|---|

## 5. Проверка целостности
1. Все ID уникальны.
2. Все внешние ключи (`machineId`, `clientId`, `masterId`) ссылаются на существующие записи.
3. Все обязательные поля заполнены.
4. Статусы заявок соответствуют допустимым значениям.

**Целостность данных не нарушена.**

## 6. Время восстановления
1. Распаковка архива: 5 секунд.
2. Копирование файлов: 2 секунды.
3. Запуск приложения: 3 секунды.
4. **Итого RTO: 10 секунд** (уложились в целевые 30 минут с огромным запасом).

## 7. Вывод
Резервная копия проверена. Восстановление работает корректно. Данные не теряются.
