# Словарь данных системы RepairIS (JSON-хранилище)

## 1. Общие принципы
В проекте используется JSON-хранилище. Каждая сущность хранится в отдельном файле. В качестве "первичного ключа" используется поле `id` (целое число, уникальное в пределах файла).

## 2. Описание сущностей

### 2.1. Пользователи (`users.json`)
| Поле | Тип | Обязательное | Описание | Ограничения |
|---|---|---|---|---|
| id | int | Да | Уникальный идентификатор | > 0, уникальный |
| login | string | Да | Логин | Уникальный |
| password | string | Да | Хеш пароля | Не пустой |
| name | string | Да | ФИО | Не пустой |
| role | string | Да | Роль | Значения: `Client`, `Manager`, `Master` |

### 2.2. Станки (`machines.json`)
| Поле | Тип | Обязательное | Описание | Ограничения |
|---|---|---|---|---|
| id | int | Да | Уникальный идентификатор | > 0 |
| model | string | Да | Модель станка | Не пустой |
| serialNumber | string | Да | Серийный номер | Уникальный |
| ownerId | int | Да | ID владельца | Ссылка на `users.json` |

### 2.3. Заявки (`orders.json`)
| Поле | Тип | Обязательное | Описание | Ограничения |
|---|---|---|---|---|
| id | int | Да | Уникальный идентификатор | > 0 |
| machineId | int | Да | ID станка | Ссылка на `machines.json` |
| clientId | int | Да | ID клиента | Ссылка на `users.json` |
| masterId | int | Нет | ID мастера | Ссылка на `masters.json` |
| status | string | Да | Статус | Значения: `Ожидает`, `В работе`, `Завершено` |
| description | string | Да | Описание | Не пустой |
| createdAt | datetime | Да | Дата создания | Формат ISO 8601 |

### 2.4. Осмотры (`inspections.json`)
| Поле | Тип | Обязательное | Описание | Ограничения |
|---|---|---|---|---|
| id | int | Да | Уникальный идентификатор | > 0 |
| requestId | int | Да | ID заявки | Ссылка на `orders.json` |
| description | string | Да | Описание неисправности | Не пустой |
| laborHours | decimal | Да | Трудоёмкость | >= 0 |

### 2.5. Сметы (`estimates.json`)
| Поле | Тип | Обязательное | Описание | Ограничения |
|---|---|---|---|---|
| id | int | Да | Уникальный идентификатор | > 0 |
| requestId | int | Да | ID заявки | Ссылка на `orders.json` |
| workCost | decimal | Да | Стоимость работ | >= 0 |
| isConfirmed | bool | Да | Подтверждена ли | `true` / `false` |
