# Миграции JSON-схемы

Так как проект использует JSON-файлы, миграции описывают изменение структуры этих файлов и скрипты для обновления старых данных.

## Миграция 001. Создание начальных файлов
**Описание:** Создание пустых JSON-файлов `orders.json`, `users.json`, `machines.json` с базовой структурой.
**Как применяется:** При первом запуске приложения, если файлов нет, создаются пустые массивы `[]`.

## Миграция 002. Добавление поля `priority`
**Описание:** В файл `orders.json` добавлено поле `priority` (int, по умолчанию 0).
**Причина:** Требование бизнеса — приоритезация заявок.
**Код миграции (C#):**
В классе `OrderAdapter` добавлен метод `MigrateAddPriority()`:
1. Читает `orders.json`.
2. Проверяет, есть ли поле `priority`.
3. Если нет — добавляет его со значением 0.
4. Сохраняет файл.

## Миграция 003. Индексы
**Описание:** В JSON нет индексов, но для ускорения поиска в коде используются словари (Dictionary) по `id`.

## Принципы
1. Миграции применяются последовательно.
2. Старые файлы не удаляются, а обновляются скриптом.
3. Перед миграцией делается резервная копия.
