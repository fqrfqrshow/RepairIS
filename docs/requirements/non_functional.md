# Нефункциональные требования RepairIS

Нефункциональные требования (NFR) описывают **качество работы** системы.
Все критерии измеримы — указаны конкретные метрики.

---

## 1. Производительность

| ID | Требование | Метрика |
|---|---|---|
| NFR-01 | Время открытия списка заявок | ≤ 2 секунды при 1000 записей |
| NFR-02 | Время сохранения заявки в JSON | ≤ 1 секунда |
| NFR-03 | Время формирования сметы | ≤ 2 секунды |
| NFR-04 | Время поиска по заявкам | ≤ 1 секунда |
| NFR-05 | Время запуска приложения | ≤ 3 секунды |

---

## 2. Доступность

| ID | Требование | Метрика |
|---|---|---|
| NFR-06 | Доступность приложения в рабочее время | ≥ 99% (9:00–18:00) |
| NFR-07 | Время восстановления после сбоя | ≤ 5 минут |
| NFR-08 | Сохранение данных при аварийном завершении | 100% (JSON записывается сразу) |

---

## 3. Безопасность

| ID | Требование | Метрика |
|---|---|---|
| NFR-09 | Хранение паролей | В хешированном виде (SHA-256) |
| NFR-10 | Разграничение прав доступа | По ролям: Заказчик, Менеджер, Мастер |
| NFR-11 | Резервное копирование JSON-файлов | Ежедневно |
| NFR-12 | Защита от несанкционированного доступа | Авторизация обязательна для всех действий |

---

## 4. Масштабируемость

| ID | Требование | Метрика |
|---|---|---|
| NFR-13 | Количество заявок без деградации | До 10 000 |
| NFR-14 | Количество пользователей | До 100 |
| NFR-15 | Возможность перехода на СУБД | Без переписывания бизнес-логики (паттерн Adapter) |

---

## 5. Удобство использования

| ID | Требование | Метрика |
|---|---|---|
| NFR-16 | Время освоения интерфейса новым пользователем | ≤ 30 минут |
| NFR-17 | Язык интерфейса и ошибок | Русский |
| NFR-18 | Понятность сообщений об ошибках | С описанием причины и способа решения |
| NFR-19 | Навигация между формами | ≤ 3 клика до любой функции |

---

## 6. Надёжность

| ID | Требование | Метрика |
|---|---|---|
| NFR-20 | Обработка ошибок при отсутствии JSON-файла | Возврат null/[] без аварийного завершения |
| NFR-21 | Покрытие кода модульными тестами | ≥ 80% (достигнуто 89%) |
| NFR-22 | Количество модульных тестов | ≥ 12 (реализовано 12) |

---

## 7. Совместимость

| ID | Требование | Метрика |
|---|---|---|
| NFR-23 | Операционная система | Windows 10 / 11 |
| NFR-24 | Платформа | .NET Framework 4.7.2+ |
| NFR-25 | Требования к железу | ≥ 4 ГБ ОЗУ, 500 МБ диска |
